# OneGate 保姆级教程

这套教程带你从一台空服务器开始，把 OneGate 跑起来、接上游、发密钥、开注册、上 HTTPS，
最后能自己备份、升级、排错。**每一步都按同一节奏写**：

> 现在做什么 → 看到什么算成功 → 失败了先查什么

命令都可以直接复制。教程只写仓库里真实存在的功能和路径；凡是无法在开源代码里核实、
只在你那台生产机上见过的现象，都会明确标注「未核实」。

## 这套教程适合谁

- 会用 `ssh` 登录服务器，但没部署过 Node 服务
- 想在 VPS 上自建一个 OpenAI 兼容入口，给几个客户端或几个人用
- 需要能说清「谁用了多少、花了多少、什么时候改过配置」

如果你只是想本地看效果、不接真实上游，直接看 [01 章](tutorial/01-install.md)的「先跑演示模式」小节即可。

## 整体路线

```
01 准备 → 02 安装 → 03 首次登录 → 04 接上游 → 05 发密钥并调用
                                   ↓
              06 注册与邮箱验证（含常见故障）→ 07 域名 / 证书 / 对外门户
                                   ↓
                          08 备份与恢复 → 09 升级与回滚 → 10 排错与安全红线
```

前三章是「能跑」，第四到六章是「能用」，第七章以后是「敢长期跑」。

## 读之前的三句话

1. **数据目录就是全部秘密。** `DATA_DIR` 里有加密后的上游密钥、密钥哈希、账户账本和加密主密钥。
   备份它等于备份整个网关，泄露它等于泄露全部密钥。教程 08 会细说。
2. **后端默认只监听 `127.0.0.1`。** 对外一律由 nginx 转发，不要把 `8787` 直接暴露到公网。
3. **先改管理员密钥，再谈别的。** 默认或弱管理员密钥等价于把控制台交给别人，见 02 章。

## 关于版本与差异

教程对应仓库当前的 `main`。以下情况会让你的界面和我写的略有出入，属正常：

- 你部署的不是最新提交
- 你用了反向代理子路径（`PUBLIC_BASE_PATH`），地址会多一层前缀
- 你的实例上有开源仓库里没有的定制页面或服务（教程会在涉及处标注「未核实」）

发现教程和代码不一致时，以代码为准，并欢迎提 issue 或 PR。
